# 🧹 Скрипты для чистого проекта

Эти скрипты помогают поддерживать проект в чистоте и не допускать накопления мусора.

## 📋 Скрипты

### 1. `clean-push.sh` - Чистый пуш
Используется **перед каждым коммитом и пушем** для очистки проекта от build-артефактов и временных файлов.

**Что делает:**
- Удаляет build-директории (`build/`, `cmake-build-*/`, `_build/`)
- Удаляет файлы CMake (`CMakeCache.txt`, `CMakeFiles/`, `Makefile`, etc.)
- Удаляет скомпилированные объекты (`.o`, `.a`, `.so`, `.dll`, etc.)
- Удаляет исполняемые файлы
- Удаляет временные файлы (`.log`, `.tmp`, `.bak`, etc.)
- Удаляет IDE мусор (`.vscode/`, `.idea/`, `.DS_Store`, etc.)

**Использование:**
```bash
./scripts/clean-push.sh
```

После выполнения скрипта:
```bash
git add . && git commit -m "ваше сообщение" && git push
```

---

### 2. `clean-clone.sh` - Чистое клонирование
Используется **для нового клонирования проекта** с автоматической очисткой и настройкой.

**Что делает:**
- Клонирует репозиторий
- Создает/обновляет `.gitignore` (если отсутствует)
- Очищает существующий мусор
- Инициализирует подмодули (если есть)

**Использование:**
```bash
./scripts/clean-clone.sh <repository-url> [directory-name]
```

**Примеры:**
```bash
# Клонировать в директорию с именем репозитория
./scripts/clean-clone.sh git@github.com:user/repo.git

# Клонировать в конкретную директорию
./scripts/clean-clone.sh https://github.com/user/repo.git my-project
```

---

## 🔄 Рабочий процесс

### Для существующего проекта:

```bash
# 1. Перед коммитом очищаем проект
./scripts/clean-push.sh

# 2. Делаем коммит и пуш
git add .
git commit -m "feat: ваша фича"
git push
```

### Для нового участника (ты или я):

```bash
# 1. Клонируем проект чисто
./scripts/clean-clone.sh <repository-url>

# 2. Переходим в директорию
cd <project-directory>

# 3. Собираем проект
./build.sh
```

## 📝 .gitignore

Файл `.gitignore` уже настроен и игнорирует:
- Build артефакты
- Скомпилированные объекты
- IDE файлы
- OS мусор
- Логи и временные файлы
- Переменные окружения

---

## 💡 Советы

1. **Запускайте `clean-push.sh` перед каждым пушем** - это гарантирует, что в репозиторий не попадет мусор
2. **Не коммитьте build-директории** - они будут у каждого свои при сборке
3. **Используйте `clean-clone.sh` при клонировании** - особенно если клонируете на новую машину

---

## ⚠️ Важно

- Скрипты работают только с файлами, которые **уже игнорируются** в `.gitignore`
- Они не удаляют исходный код или важные файлы проекта
- Перед первым запуском убедитесь, что все важные изменения закоммичены
