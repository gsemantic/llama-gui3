## Инструкция по запуску

1. Соберите плагин:
```bash
cmake --build build --target wp_coder
```

2. Скопируйте конфигурацию:
```bash
cp plugins/user_plugins/wp_coder/plugin.json build/plugins/wp_coder.json
```

3. Запустите GUI:
```bash
./run_gui.sh
```

4. Настройте проект в меню **WordPress → Проект**
