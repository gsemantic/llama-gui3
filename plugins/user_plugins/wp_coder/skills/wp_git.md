# wp_git
Описание: работа с Git в проектах WordPress
При работе с Git в проектах WordPress:
- Используй `git status` для проверки изменений перед коммитом.
- Делай `git diff` для просмотра изменений в файлах.
- Используй `git log` для просмотра истории коммитов.
- Коммить только связанные изменения с одним логическим объектом.
- Пиши осмысленные сообщения коммитов на английском языке.
- Используй `git add <файл>` для добавления конкретных файлов.
- Для WordPress проектов исключай из коммита `wp-config.php` и `.env`.
- Проверяй `.gitignore` перед добавлением новых файлов.
