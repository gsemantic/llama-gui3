# wp_database
Описание: работа с базой данных WordPress через wp-cli
При работе с базой данных WordPress:
- Используй `wp db query` для выполнения SQL-запросов.
- Всегда делай бэкап перед изменением структуры БД: `wp db export backup.sql`.
- Для поиска данных используй `wp db search` вместо ручных SQL-запросов.
- Проверяй опции через `wp option get` и `wp option update`.
- Для миграций используй `wp db prefix` для проверки префикса таблиц.
- Не удаляй таблицы ядра WordPress без крайней необходимости.
- Используй `wp db optimize` для оптимизации таблиц после массовых изменений.
