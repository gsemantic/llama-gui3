# Улучшения плагина WP Coder

## Добавлено в версии 0.2.0

### 1. Git-интеграция
- **Инструменты:** `git_status`, `git_diff`, `git_log`, `git_commit`
- **UI:** Отдельное окно «Git» с кнопками для быстрых операций
- **Навык:** `wp_git.md` — правила работы с Git в проектах WordPress

### 2. Улучшение UI/UX
- **Окно «Файлы»:** Дерево файлов с фильтрацией и быстрыми действиями
- **Горячие клавиши:** Добавлены сочетания клавиш для новых окон
- **Навигация:** Улучшенное меню WordPress с дополнительными пунктами

### 3. Расширение инструментов
- **wp_db:** Выполнение SQL-запросов через wp db query
- **wp_media:** Работа с медиафайлами (список, импорт, удаление)
- **wp_option:** Чтение опций WordPress
- **Навыки:** `wp_database.md` и `wp_media.md` — инструкции по работе с БД и медиа

### 4. Улучшение системного промпта
- Добавлены описания новых инструментов
- Добавлены ссылки на навыки для Git
- Улучшены инструкции по работе с инструментами

## Тестирование

### Ручное тестирование
1. Запустите GUI: `./run_gui.sh`
2. Откройте WordPress → Проект (Ctrl+Shift+W)
3. Настройте путь к WordPress проекту
4. Откройте WordPress → Агент (Ctrl+Shift+E)
5. Проверьте базовые команды:
   - `выполни git_status`
   - `выполни repo_map`
   - `прочитай файл wp-config.php`

### Автоматическое тестирование
```bash
# Сборка плагина
cmake --build build --target wp_coder

# Проверка зависимостей
ldd build/plugins/libwp_coder.so

# Проверка символов
nm -D build/plugins/libwp_coder.so | grep ll_plugin
```

## Известные ограничения

1. **headless_render** требует Chromium в PATH
2. **wp_cli** требует установленный wp-cli
3. **git** требует установленный git
4. **deploy** для ftp/sftp требует внешний deploy.sh
