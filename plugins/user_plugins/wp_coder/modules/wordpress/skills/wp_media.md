# wp_media
Описание: работа с медиафайлами WordPress
При работе с медиафайлами WordPress:
- Используй `wp media list` для просмотра списка медиафайлов.
- Загружай файлы через `wp media import <путь>`.
- Для генерации миниатюр используй `wp media image-size`.
- Проверяй метаданные через `wp media meta get`.
- Удаляй неиспользуемые файлы через `wp media delete`.
- Используй `wp media regenerate` для пересоздания миниатюр.
- Для импорта из URL используй `wp media import <url> --title="..."`.
