# wp_hook
Описание: правильные хуки WordPress (action/filter/shortcode)
При написании хуков WordPress строго соблюдай:
- `add_action( 'init', 'my_init' );` — первый аргумент имя хука (строка), второй — имя коллбэк-функции (строка), третий — приоритет (int, по умолчанию 10), четвёртый — число аргументов.
- `add_filter( 'the_title', 'my_title_filter', 10, 1 );` — фильтр ДОЛЖЕН возвращать значение через `return`.
- Имя коллбэка уникально в глобальной области; префиксуй функции (на_dir_...), чтобы не конфликтовать.
- Для shortcode: `add_shortcode( 'mysc', 'my_shortcode_cb' );` коллбэк принимает `$atts, $content, $tag` и возвращает строку.
- Никогда не выводи `echo` внутри фильтра — только `return`.
- Хуки загрузки темы: `after_setup_theme`, `init`, `wp_enqueue_scripts` (для стилей/скриптов).
