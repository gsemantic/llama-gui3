## Инструкция по запуску

1. **Сборка плагина:**
```bash
cd /home/Alex/projects/llama-b7472-bin-ubuntu-x64/llama-gui
cmake --build build --target wp_coder
```

2. **Копирование конфигурации:**
```bash
cp plugins/user_plugins/wp_coder/plugin.json build/plugins/wp_coder.json
```

3. **Запуск GUI:**
```bash
./run_gui.sh
```

4. **Настройка проекта:**
- Откройте меню **WordPress → Проект** (Ctrl+Shift+W)
- Укажите корень локального WordPress
- Настройте php-cli и URL сайта

5. **Использование агента:**
- Откройте меню **WordPress → Агент** (Ctrl+Shift+E)
- Введите задачу и нажмите «Отправить»

## Известные ограничения

1. **headless_render** требует Chromium в PATH
2. **wp_cli** требует установленный wp-cli
3. **git** требует установленный git
4. **deploy** для ftp/sftp требует внешний deploy.sh
