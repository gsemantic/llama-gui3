# Два «headless» в llama-gui

В проекте есть две независимые сущности со словом «headless». Их легко
перепутать — они не связаны друг с другом.

## 1. Серверный режим приложения (без GUI)

- Включается флагом `--headless` / `-s` (или `--server`, `--cloud`, `--proxy`)
  в `src/main.cpp`.
- Запускает **llama-server без графического интерфейса**: приложение поднимает
  HTTP-endpoint для внешних клиентов (других программ, qwen-cli и т.п.).
- Не имеет отношения к браузеру и не открывает никаких веб-страниц.
- В справке и UI называется **«серверный режим (без GUI)»**.

## 2. Headless-браузер (Chromium)

- Общая библиотека `libs/headless_browser/` (единственный источник правды,
  используется и основным приложением, и плагинами вроде news_rewriter).
- Рендерит веб-страницы **без отображения окна браузера**: исполняет JS и
  возвращает сериализованный DOM (`--dump-dom`) либо делает скриншот (PNG).
- Нужен для сайтов, отдающих контент через JavaScript (SPA, напр. VK.ru),
  где обычный HTTP-запрос возвращает пустую «оболочку».
- Доступен тремя способами:
  - **Панель «Headless-браузер»** в основном окне (меню Window → Headless-браузер):
    ввод URL → DOM/скриншот → «Отправить в чат» (например, для разработки
    сайтов совместно с AI-кодером).
  - **Агент `web_render_agent`** (официальный плагин агентов, собирается при
    `BUILD_AGENT_PLUGINS=ON`) с действиями `render` / `screenshot` / `available`
    / `thin`. Доступен из основного приложения двумя путями:
    - **Окно «Агенты»** (меню Window → Агенты): список загруженных агентов,
      включение/отключение. Плагины агентов ищутся в `plugins/agents` рядом с
      исполняемым файлом (`build/plugins/agents/...` в дереве сборки).
    - **Чат-команда** вида `/agent web_render_agent render url=<URL>` (и
      `/agent web_render_agent screenshot url=<URL> out_path=<PATH>`,
      `available`, `thin html=<HTML>`). Результат агента выводится в чат
      (как сообщение ассистента). Пример для разработки сайтов с AI-кодером:
      `/agent web_render_agent render url=https://example.com`.
  - Напрямую из кода через `headless_browser::render_dom()` / `screenshot()`.

## Как не запутаться

| Термин | Что это | Где |
| --- | --- | --- |
| серверный режим (без GUI) | llama-server без окна | `--headless` в `main.cpp` |
| headless-браузер | Chromium рендерит страницы | панель «Headless-браузер», `web_render_agent`, `libs/headless_browser` |
